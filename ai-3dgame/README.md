
# 🇮🇳 AI 3D Game Maker (Desi Version)

**Namaste Developers! 🙏**

Welcome to the **AI 3D Game Maker**! Ye project puri tarah se **Atmanirbhar** hai aur aapko allow karta hai ki aap bas English (ya Hinglish!) mein likh kar awesome 3D games aur simulations bana sakein using PyGame.

Ghar bethe game development seekho aur banao, powered by **DeepSeek R1** and **OpenAI**! 🚀

---

## 🔥 Kya Khas Hai Isme? (Features)

*   **Bole Toh Ek Number Generation**: Bas type karo kya chahiye, aur ye AI code likh dega.
*   **DeepSeek Ka Dimaag**: Use karta hai powerful R1 reasoning model logic ke liye.
*   **Browser Automation**: Trinket.io par code khud run karega, jadu ki tarah! ✨
*   **Modular Code**: Clean code structure, bilkul professional.

---

## 📂 Project Structure

Project ko acche se organize kiya gaya hai:

- **`main.py`**: Yahan se shuru hota hai khel (Entry Point).
- **`config.py`**: Sab settings aur secrets yahan hain.
- **`llm_service.py`**: AI models se baat karne wala dimag.
- **`automation_service.py`**: Browser automation ka control center.
- **`ui_components.py`**: App ko sundar banane wala code.
- **`.env`**: Aapke secret API keys ka tijori (Secret Vault).

## 🚀 Kaise Run Karein? (How to Run)

Follow these simple steps, boss:

### 1. Repository Clone Karo
Terminal kholo aur ye command lagao:
```bash
git clone https://github.com/RohitBit-25/Project-Ai-Projects.git
cd Project-Ai-Projects/ai-3dgame
```

### 2. Masala (Dependencies) Install Karo
Sab zaruri libraries install karne ke liye:
```bash
pip install -r requirements.txt
```

### 3. Apna Secret `env` Set Karo
Project folder mein ek `.env` file banao aur apne API keys daalo:
```env
DEEPSEEK_API_KEY=tumhara_deepseek_key_yahan
OPENAI_API_KEY=tumhara_openai_key_yahan
```

### 4. Shuru Karo! (Launch App)
Ab bas ye command run karo aur jalwa dekho:
```bash
streamlit run main.py
```
